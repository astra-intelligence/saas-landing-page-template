# Modern SaaS Landing Page Template

A premium, ready-to-use SaaS landing page template built with modern HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just a single HTML file you can customize and ship.

## Features

- Dark theme with gradient accent colors
- Responsive design (mobile, tablet, desktop)
- Hero section with badge, headline, and CTA buttons
- Feature cards (6-column grid with icons)
- 3-tier pricing table
- FAQ accordion
- Call-to-action section
- Smooth scroll animations (Intersection Observer)
- Clean, semantic HTML
- No external dependencies

## Customization

The template uses CSS custom properties (variables) for easy theming. Change colors, fonts, spacing, and layout in the `:root` block at the top of the CSS.

```
:root {
  --accent: #6c5ce7;
  --accent-light: #a29bfe;
  --bg: #0a0a0f;
  // ... customize away
}
```
