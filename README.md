## Quick Customization

Edit CSS custom properties in the `:root` block:

```css
:root {
  --accent: #6c5ce7;       /* Primary accent color */
  --accent-light: #a29bfe; /* Lighter accent */
  --bg: #0a0a0f;           /* Background */
  --text: #e8e8f0;         /* Text color */
}
```
